# 14 — Glosario rápido

← [13: Async](13-async.md) | [Indice](INDICE.md)

---

| Termino | Significado |
|---------|-------------|
| **Articulo** | `el`, `la`, `un` — indican quien es dueño de una variable |
| **Binding** | Asignar un valor a un nombre |
| **Borrow** | Prestamo: usar un valor sin ser dueño |
| **Compilación** | Convertir .fc a .exe |
| **Comodín** | `_` — atrapa cualquier valor no cubierto |
| **Dueño (owned)** | Variable que controla la memoria |
| **Genérico** | Funciona con cualquier tipo (`<T>`) |
| **Heap** | Memoria dinámica |
| **Inferencia** | El compilador deduce el tipo solo |
| **Interpolación** | Meter variables en strings con `{var}` |
| **Ownership** | Sistema de propiedad de datos |
| **Palabra** | Texto fijo en el programa |
| **Pila (stack)** | Memoria rápida, automática |
| **Prestado (borrowed)** | Solo lectura, no se modifica |
| **Rango** | `0..5` (exclusivo) o `0..=5` (inclusivo) |
| **Subjuntivo** | `fuese` para casos improbables |
| **Texto** | Texto dinámico, hay que liberarlo |
