# Falcato (`*.fc`)

**Lenguaje de programación de bajo nivel, iberohablante.**

Forjado desde cero sobre LLVM. Poder. Eficiencia. Iberofonía.

Falcato explota la riqueza semántica del español — género gramatical, tiempos verbales,
ser/estar, prefijos productivos — como *sistema de tipos y ejecución* en lugar de
meras palabras reservadas traducidas.

```falcat
función principal(): Entero32 {
    el mensaje: Palabra = "¡Falcato forja poder!";
    imprimir(mensaje);
    retornar 0;
}
```

## Filosofía

| Pilar | Significado |
|-------|-------------|
| **Poder** | Control total del hardware. Sin runtime oculto. Sin abstracciones gratuitas. |
| **Eficiencia** | Cero costo en tiempo de ejecución. Lo que no se usa, no se paga. |
| **Iberofonía** | El español como lenguaje de programación de sistemas. No una traducción, sino un diseño que aprovecha sus dimensiones semánticas únicas. |
